# Lot K1bc — Les fiches de Jump et de Track : plus aucun jeu sans fiche

Conception : `docs/plateforme/kit-de-jeu.md` (K0) ; K1 : `lot-K1-fiche-de-jeu.md`. Pour les joueurs : **rien**. Aucun golden, aucune `*_VERSION`, aucune table, aucun fichier de jour dans le diff. **Deux commits annulables séparément** : Jump (`31ac80c`, puis son `fixup!` `274bdea`), Track (le suivant).

## Les deux fiches, avec leurs écarts au § 3 de K0
- **Jump** (`config/jeux/jump.json`) : tout le tableau de K0, plus : **`jump_deaths`** (vidée) — K0 ne l'avait pas vue, le test de cohérence l'exige ; **`coque` = l'encre du socle `#2A1E16`** (K0 ne donne que le jaune ; l'étiquette de Jump est un papier bordé d'encre) ; `medailles.bareme: []` (les seuils sont figés avec le niveau) ; `rejeu: { unitesServeur: 1, ticksParUnite: 5000 }` (coût proportionnel à la durée) ; `accrocheTheme: "jump.replique."` (la réplique du thème du jour) ; versions dont `MEDAILLES_ASSOUPLIES_VERSION` ; la zone serveur contient les niveaux figés (le serveur les lit : catégorie `jump` + plateforme, comme avant).
- **Track** (`config/jeux/track.json`) : **`dossiers: { app: "web", sim: "sim" }`** (champ facultatif, absent pour les autres jeux), code `cdj`, préfixe `cdj:`, neuf tables dites une à une (`results`, `garage_choices`, `salon_*` ×5 vidées ; `circuits`, `planning` gardées — Salon et Garage restent propres à Track : la fiche les déclare, elle ne les décrit pas), médailles `facteurs-auteur` `[0,92 ; 1,045 ; 1,07 ; 1,13]`, **`jours.registre`** (`packages/sim/src/jours-track.json`, sans dossier ni preuve), classement `ms` ↑, cumul, partage `rang`, outils d'administration.
- **Ajouts au schéma**, tous facultatifs : `dossiers`, `accrocheTheme`, `rejeu.ticksParUnite`, `e2e.regression`, `jours.registre`, `zones.documents` (deux visions de Nathan, `docs/seed.md` et `docs/guide-technique.md`, que la CI range avec Track sans que son lot les écrive : sans eux la portée d'une PR changeait).
- **« Un jeu ne réclame que ses propres chemins » tient** : `prefixesDeZones(id, dossiers)` ; les noms d'avant la règle sont **nommés un par un** (`CHEMINS_HERITES` : `measure-jump.ts`, les fichiers `cdj.ts`/`salon.ts`/`garage*.ts` de Track et ses documents ; `TABLES_HERITEES` ; `PREFIXES_HERITES`) ; deux fiches ne déclarent pas le même dossier (`validerEnsemble`). Testé : un jeu n'hérite jamais des noms d'un autre.
- **Restent dans `e2e/zones.json`** : les zones partagées et **10 specs du portail et de la plateforme qui vivent dans `apps/web/e2e`** (aucune zone de Track : `portail`, `domaine`, `amis`, `iphone`, `manette`, `admin-panneau`, `admin-jump`, `diffusion`, `portail-jour`, `portail-journee`) ; 54 specs web, 17 zones `track-*` et `api-track` passent dans la fiche.

## Ce qui a disparu avec `JEUX_SANS_FICHE`
Le tableau lui-même ; dans `ficheSorties` les ids écrits « track, jump » ; dans le portail : `PREMIER_JOUR_TRACK/JUMP` (le numéro local vient de `premierJour`), la table `JEUX` du classement, `NOM_JEU`, les ternaires `"track" ? … : "jump"` des titres, accroches et noms, les tuiles « Track finis » / « Jump finis » écrites à la main, la réplique de Jump écrite en dur ; dans `@cdj/ui` la bascule `jeu === "track" ? … : …` de `etiquetteDe` et les valeurs de `jetons.ts` (asphalte, coque, jaune, polices : les valeurs de la fiche) ; dans la musique les scènes de Track et de Jump ; dans les scripts : `JEUX`, `ZONES`, `CATEGORIES`, `RULES`, `E2E_DIRS`, `JEUX_E2E`, `PARTS_COMPLETES`, `LAYOUT` de `site.mjs` (les jeux viennent des fiches).

## Comparaisons avant / après (même session, `HEAD` de départ `b0e75e6` contre chaque commit)
- **Scripts de CI** (`ci-scope`, `zones-jeu`, `ci-zones` : 4 modes × 4 branches × 5 jeux d'étiquettes × ~65 listes de fichiers, `matriceComplete`) : **la catégorie des 3 623 fichiers du dépôt est identique** ; specs e2e, parts, matrices et verdicts de zones identiques. Différences, toutes expliquées : (1) le résumé dit « Track », « Jump » à la place de « DailyTrack », « DailyJump » ; (2) **+1 test unitaire** lancé pour un fichier de Track (`packages/core/test/fiches.test.ts`, qui cite maintenant `apps/web/`) et **+6** pour un niveau figé de Jump (les tests qui lisent la fiche) ; (3) `@cdj/tower` entre dans les paquets d'application du graphe (personne ne l'importe). **Une perte a été trouvée et corrigée** : un niveau figé ne lançait plus 11 tests (`productionSite`, `site`…), le dossier n'étant plus écrit en dur dans le code qui le lit — le graphe de la CI cite maintenant les `jours.dossier` des fiches (`graphe`, `ci-zones.mjs`) ; les tests lancés après sont un sur-ensemble des tests d'avant.
- **Site** (`site.mjs`, 638 fichiers avant et après) : mêmes noms, mêmes tailles, mêmes empreintes pour `track/`, `jump/`, `tower/`, les images de partage, le manifeste, la musique, les jours ; ne changent que les chunks hachés du portail et les 7 pages HTML qui les nomment.
- **`dist` des trois jeux : identiques à l'octet** (`diff -rq` vide, avant / après).
