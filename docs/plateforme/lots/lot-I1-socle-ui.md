## 2. Le moteur de traduction (`packages/ui/src/i18n.ts`, `formats.ts`, `catalogue.ts`)
- `traducteur(langue, ...catalogues)` : clés lisibles (`portail.jeux.titre`), paramètres nommés (`{temps}` ; un nombre est écrit au format de la langue), pluriels par `Intl.PluralRules` sur le paramètre `n` (`{ one, other }` : « 0 mort » / « 0 deaths »). ≈ 60 lignes, aucune bibliothèque ; les deux langues sont chargées avec l'application (le budget le permet : § 5).
- Formats (`Intl`, testés) : `formatTemps` (`31,402 s` / `31.402 s`, `1:02,345` au-delà d'une minute), `formatNombre` (`1 284` / `1,284`), `formatRang` (`1er`, `14e` / `1st`, `2nd`, `3rd`, `14th`), `formatDate` (« mardi 20 octobre » / « Tuesday, October 20 », capitale en tête de ligne), `formatDateCourte` (« Mar. 20 oct. » / « Tue, Oct 20 »), `formatNumeroJour` (`n° 12` / `#12`). Espace insécable U+00A0 entre nombre et unité.
- Catalogues : **commun** (`packages/ui/src/catalogue.ts` : composants, noms des jeux, **les 46 codes d'erreur**), **portail** (`apps/portail/src/catalogue.ts`), **vitrine** (`apps/portail/src/catalogueVitrine.ts`).
- **Tests** : parité (`packages/ui/test/catalogues.test.ts` : mêmes clés, aucune valeur vide, mêmes paramètres, mêmes formes plurielles, aucune clé dans deux catalogues ; chaque code de `apps/api/src/codesErreur.ts` traduit, et rien d'autre) ; **refus des chaînes en dur** (`chainesEnDur.test.ts` : texte du HTML, attributs `title` / `aria-label` / `placeholder` / `alt`, `meta description` ; en TypeScript, littéraux affectés à `textContent`, `innerText`, `innerHTML`, `title`, `placeholder`, `alt`, `ariaLabel`, passés à `setAttribute`, `append`… ou aux options de texte des composants ; exception par une marque commentée `i18n-ok: <raison>`). Le détecteur est testé sur des exemples positifs et négatifs. **Prêt pour les jeux** : `packages/ui/test/applications.ts` (`DOSSIERS_SANS_CHAINES_EN_DUR`, `CATALOGUES`) — I4 et I5 y ajoutent leurs dossiers et catalogues.

## 3. La langue commune (`@cdj/profile`, `src/langue.ts`)
- Clé **`cdj:langue`** (`fr` | `en`), avec les autres clés `cdj:*` : **la même pour le portail et les jeux** (même origine). Première visite : la **première** langue de `navigator.languages`, tout ce qui commence par `fr` → français, sinon anglais (`detecterLangue`) ; ensuite le choix fait est mémorisé (`ecrireLangue`). **Seul un choix explicite est écrit** : tant que le joueur n'a rien choisi, la détection suit son navigateur. `lireLangue(stockage, navigator.languages)` est la fonction que les jeux appelleront (I4, I5) : ils n'auront pas à toucher à la détection. Les jeux ne sont pas modifiés dans ce lot.
- Changer de langue au portail met à jour l'écran **sans recharger**, `<html lang>`, le titre et la description ; le focus reste sur le bouton de langue.
- Nouvelle donnée gardée dans le navigateur → **la page des mentions le dit** (« ta langue (français ou anglais, si tu l'as choisie sur le portail…) », vérifié par `mentions.test.ts`).

## 4. Les codes d'erreur du serveur (`apps/api`) — doc : `docs/plateforme/codes-erreur.md`
- **Forme gardée** : le code était déjà dans le champ `error` (`{ error, message, …détails }`) ; aucun nouveau champ, **aucun message changé** (tous les tests existants passent sans modification de leurs assertions). ## 9. Écarts à la charte — **proposés, non appliqués à la charte**

3. **Échelle typographique** : 14 px (logo de la barre des jeux, § 2), 16 px (bouton de marque, maquette) et 21 px (logo, § 2) ne sont pas dans l'échelle du § 4 ; proposés en ajout.
4. **Couverture des polices** : aucune police n'a l'espace fine insécable U+202F (qu'`Intl` met entre les milliers en français) → `formatNombre` la remplace par U+00A0 ; **Lilita One n'a pas d'espace insécable** (le navigateur prend celle de la police de repli) ; « Ÿ » (U+0178) est dans le sous-ensemble « latin-ext », non chargé (rarissime en français). Lilita One porte un nom de police réservé (« Reserved Font Name ») : le sous-ensemble est celui distribué par Fontsource et Google Fonts sous ce nom, comme partout ; à garder en tête si on la modifie un jour nous-mêmes.
5. **États non décrits par la charte** (choix du lot, à valider à l'œil dans la vitrine) : survol du bouton de marque = encre (invisible contre l'asphalte : le bouton de marque n'est pas fait pour l'asphalte), du secondaire = crème 2, de « Courir » = `--track-livree-texte`, de Jump = texte papier ; **désactivé** = aplat crème 2, texte encre douce, bordure pointillée, sans ombre (jamais de transparence).
