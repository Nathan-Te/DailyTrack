## Les amis dans le classement (lot F2)
Contrat : `docs/plateforme/lots/lot-F2-amis.md` ; composants : `packages/ui/CLAUDE.md`, « Les amis (lot F2) » ; client : `packages/profile/CLAUDE.md`. **Tower a un classement (à la hauteur), donc le sélecteur « Tous · N / Amis · N » y est** : dans le dialogue « Tout le classement › » (accueil et arrivée), jamais en partie.
- **Les amis sont à la demande ; le dialogue reste dans l'accueil.** `monterClassement` (`classementUi.ts`) garde le dialogue, son voile et son focus (`suivreDialogue`, partagé avec la pause et la fin du jeu : le sortir de l'accueil le faisait passer dans la mesure de `tower.jeu`, dépassée de 675 o) et ne porte que **un `import()`** du second morceau, `amisClassement.ts` (+ `amisClassement.css`, `@cdj/ui/src/amis`, `CATALOGUE_AMIS`), appelé à chaque ouverture **si l'accueil ou le jeu a donné une `SourceAmis`** (`{ base, id, date }`) ; le morceau ne fait rien sans identité, serveur et jour (le dialogue est alors celui d'avant, sans sélecteur). Il **n'importe de `classementUi.ts` que des types** (les lignes et l'en-tête lui sont prêtés par `HoteAmis` : un import en aurait fait éclater des morceaux dans le premier chargement, mesuré +500 o), et le dialogue **n'importe pas `@cdj/profile`** (l'identité lui vient de `SourceAmis.id`) ; les lignes touchables portent `data-ref`. La logique pure (lecture de la réponse, ligne touchable, `?filtre=` dans l'adresse) est `amisLogique.ts` (`test/amisLogique.test.ts`).
- **« Amis »** : `GET /api/tower/day/<date>/board?filtre=amis` (en-tête `X-Player-Id`), requête faite **seulement au choix d'« Amis »** (ou à l'ouverture si l'adresse porte `?filtre=amis`) ; toi et tes amis, tous (pas de limite de 50), `rank` = rang entre amis, `rangGeneral` au toucher/survol (« 8e sur 412 »), ta ligne en moutarde, les amis sans partie en bas (« Pas encore joué aujourd'hui » / « pas encore joué »), `classementAmisVide` sans ami. Le compteur « Amis · N » est lu **une seule fois par ouverture** (`lireAmis`). Une erreur ramène à « Tous » avec une ligne discrète (`messageErreur`). Le choix s'écrit dans l'adresse (`history.replaceState`, les autres paramètres gardés).
- **La feuille d'un joueur** : le nom d'un autre joueur (« Tous » comme « Amis », et les absents) est un bouton qui ouvre `feuilleJoueur` (`ficheJoueur(ref, date)`, « Ajouter en ami » / « Retirer ») ; ta ligne n'ouvre rien. **Manette** : la ligne `.dj-feuille` de `ECRANS_MANETTE` est `ECRAN_MANETTE_FEUILLE` recopiée (importer le socle dans `manetteEcrans.ts` ferait charger les amis à la première manette ; `test/manette.test.ts` vérifie l'égalité).
- **Budget** : `tower.jsCss` 39 916 (marge 84, +247) ; `tower.jeu` 169 141 (plafond 169 200, inchangé) — `docs/plateforme/budgets.md`.
