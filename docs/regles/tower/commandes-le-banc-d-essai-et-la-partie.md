# Commandes (le banc d'essai et la partie)

> Déplacé **mot pour mot** de `docs/tower/consignes.md` (lot T1, économie de jetons) : rien n'est réécrit, les règles sont en vigueur. Le renvoi est dans [`apps/tower/CLAUDE.md`](../../../apps/tower/CLAUDE.md).

## Commandes (le banc d'essai et la partie)
- `npm test` (ou `npx vitest run --project sqlite packages/tower-sim apps/tower`) : pureté (`lab/`, `lab/a/`, `src/`, `scenarios/`), trigonométrie, virgule fixe, pièces, **banc d'essai et empreintes de Node pour A et B**, copie du monde, physique élémentaire, **la partie** (`test/partie.test.ts` : une règle, un test) et le `.wasm` (`apps/tower/test/rapierWasm.test.ts`).
- `UPDATE_GOLDEN=1 npx vitest run --project sqlite packages/tower-sim/test/banc.test.ts` : régénère `banc-golden.json` (seulement en comprenant pourquoi : un changement de moteur, de réglage ou de banc).
- `npm run build -w @cdj/tower && npm run e2e -w @cdj/tower` : le déterminisme dans Chromium (le banc et **les trois rediffusions de référence**, lot T2) et **le parcours d'une partie** (`e2e/partie.spec.ts`, Chromium seulement) ; `E2E_ALL_BROWSERS=1` ajoute Firefox et WebKit (petit ensemble `@navigateurs`). **En CI : `ci.yml`, comme Track et Jump** (lot R15, voir « La CI de Tower » plus bas) ; `npm run verifier` lance en local les mêmes specs que la CI de PR. `node apps/tower/tools/poids.mjs` (après la construction) : le poids par étape (page, jeu, physique, anglais).
- Lot T3 : `npm run preparer:tower -w @cdj/tower-sim -- --du … --au …` (les jours préparés : médailles et preuve), `npm run mesures-t3:tower -w @cdj/tower-sim` (≈ 30 min : coût du bot, hauteurs sur 30 jours, deux joueurs simulés, coefficient du repli ; écrit `dist/mesures-t3.json`), `?seed=…&bot`, `?seed=…&theme=…`.
- Lot T2 : `npm run golden:tower -w @cdj/tower-sim [-- --chercher]` (le golden), `npm run figer:tower -w @cdj/tower-sim -- --du … --au …` (les jours figés), `npm run mesures-t2:tower -w @cdj/tower-sim` (≈ 3 min : coût d'un rejeu, taille d'une rediffusion, borne).
- `npm run mesures:tower -w @cdj/tower-sim` (≈ 5 min) : coût d'un rejeu, stabilité, coût d'un tour de bot. `npm run poids:tower -w @cdj/tower-sim` (après la construction) : poids compressé par moteur.
- `npm run calibrer:tower -w @cdj/tower-sim` (≈ 7 min, **à ne relancer que si la table doit changer**) : un bot glouton joue la suite sur A et fige `lab/bancTable.ts`.
- Lot T8 : `npm run stabilite:tower -w @cdj/tower-sim -- --variante=v4,v5` (le diagnostic de la stabilité, ≈ 30 s par variante ; `--liste` : les variantes ; `--ecrire=<fichier>` : le détail) ; le bot imparfait du corpus est calculé une fois (≈ 2 min, 4 fils).
- Lot T6 : `npm run alignement:tower -w @cdj/tower-sim` (le diagnostic de l'alignement, 3 s, versions 3 et 4 côte à côte), **`/?scenario=alignement`** (la suite pour poser juste), `?visee=0` (sans la visée).
- La page : `npm run dev -w @cdj/tower`, puis **`/`** (le contenu d'aujourd'hui), **`/?seed=AAAA-MM-JJ`** (le contenu de ce jour ; sur la production une date future est refusée, voir R9 ci-dessous), **`/?scenario=paliers&effet=lierre|figee|petite|geante|vent|glissante`** (une tour à 9 m : pose une pièce, franchis 10 m, regarde l'effet), **`/?scenario=emboitement`** (lot T8 : la niche latérale et le trou rétréci, pour essayer le taquet et la tolérance), **`/?scenario=essai`** (la partie, au clavier : ← → déplacent, ↑ ou X tournent, ↓ ou Espace maintenu descendent, Échap ou P : pause ; `&tactile=1` montre les boutons), **`/?scenario=essai&debug&tune`** (la ligne d'état et les curseurs de sensation : délai et cadence de répétition, vitesse de chute, facteur de descente, hauteur d'apparition ; la simulation les prend à la partie suivante), et la démonstration du lot T0 : `/?scenario=banc&engine=a|b`, `…&libre`, `…&debug&tune`. **`?scenario`, `?effet`, `?debug` et `?tune` sont fermés en production** (règle R9 : `urlOptions.ts`) ; **`?seed=` suit celui de Jump** : sur la production une date future est refusée (le contenu d'aujourd'hui s'ouvre, une ligne le dit), sur un aperçu de branche ou en local toutes les dates sont ouvertes.
