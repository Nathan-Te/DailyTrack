## Les amis (lot F2)
README : `docs/plateforme/lots/lot-F2-amis.md` ; composants : `packages/ui/CLAUDE.md`, « Les amis (lot F2) » ; client : `packages/profile/CLAUDE.md` ; serveur : `apps/api/CLAUDE.md`. **Tout le code des amis est à la demande** (`import()` de `@cdj/ui/src/amis` et de son vocabulaire `catalogue.amis`) : l'accueil n'en embarque rien (test `construction.test.ts`).
- **`/classement/`** (`classement.ts`, `classementAmis.ts` pur, `classementDonnees.ts`) : avec une identité, le sélecteur « Tous · N » / « Amis · N » (`role="radiogroup"`, sous les onglets de vue ; sa place est réservée tant que les composants arrivent) ; **`?filtre=amis`** dans l'adresse avec `?date=` et `?vue=` (`adresseDuClassement`, dans cet ordre). « Amis » (`GET /api/portail/classement?filtre=amis`, l'identifiant en `X-Player-Id`) n'est lu **qu'au choix** (ou si l'adresse le porte) ; le nombre d'amis vient d'**un seul** `GET /api/amis` à l'ouverture. Lignes « Amis » : toi et tes amis, tous (pas de limite de 50), `rang` = rang entre amis, ta ligne en moutarde ; les amis qui n'ont rien fini en bas (« pas encore joué ») ; sans ami, `classementAmisVide` ; une erreur (hors ligne, `invalid_filter`, profil inconnu) = une ligne discrète (`classement.amis.indispo`) et « Tous ». **La ligne d'un autre joueur est un bouton** (`.classement-ligne__bouton`, 44 px) : elle ouvre `feuilleJoueur` (`ficheJoueur(ref, date)`, « Ajouter en ami » / « Retirer ») ; fermée après un changement dans « Amis », la liste est relue ; la tienne n'est pas touchable. Pseudos en `textContent`. Manette : la feuille est `ECRAN_FEUILLE` de `manette.ts` (l'égale de `ECRAN_MANETTE_FEUILLE`, testée : l'importer ramènerait les composants dans le menu de chaque page) ; LB / RB changent d'onglet de vue, jamais le sélecteur.
- **`/amis/`** (`amis/index.html`, `amisPage.ts`, `amisDonnees.ts` pur, `amisPortail.css`) : « Mes amis » — ajouter par pseudo (suggestions), « Inviter un ami (lien) », ta liste (« vous deux » / « ajouté par toi », « Retirer », 100 au plus) ; ouverte depuis le profil (section « Amis », un lien : aucune requête de plus). **`?invitation=<jeton>`** : `rangerInvitation` dès le chargement (le jeton passe dans `sessionStorage` `cdj:invitation` et **quitte l'adresse tout de suite**), `voirInvitation` (marche sans profil) puis la carte « {pseudo} t'invite sur Du Jour ». **Accepter sans profil** demande un pseudo : un identifiant est tiré **en mémoire**, le serveur crée le profil, et **l'identité locale (`cdj:player`, `cdj:name`) n'est écrite qu'une fois l'amitié faite** (`accepterEtEcrire` : un pseudo pris, un lien révoqué, une liste pleine ne laissent rien) ; le jeton est oublié après l'acceptation et pour un refus définitif (`invalid_invitation`, `friend_exists`, `friend_self`). Les sections sont construites une fois (le lien d'invitation n'est montré qu'à sa création) ; seule la langue refait la page. Page d'entrée comme les autres : en-tête iOS, aperçu de partage (`apercu.amis.*`, image du portail), **`noindex`**, `PAGES_MANETTE.amis` (le champ du pseudo, ou « Accepter »).
