## Le panneau d'administration (lot N1)
README : `docs/plateforme/lots/lot-N1-admin-connexion-tableau-joueurs.md` ; serveur : `apps/api/CLAUDE.md`, « Administration (lot N1) » ; étapes de Nathan : `docs/plateforme/admin.md`.
- **`/admin/`** (`admin/index.html`, `src/admin.ts` la page, `src/adminDonnees.ts` le client et les calculs purs — testés par `test/admin.test.ts` —, `src/admin.css`) : une page **privée pour l'éditeur**, `noindex` (balise **et** en-tête), **en français seulement, hors des catalogues des joueurs** (aucun catalogue EN à tenir ; exemptée du test des chaînes en dur avec sa raison, `packages/ui/test/applications.ts`). Elle suit la charte (jetons, composants du socle : `logo`, `bouton`, `tuile`, `medaille` ; fonds unis, traits de 2–3 px, ombres nettes, **barres pleines sans dégradé**) et n'écrit jamais de HTML (`textContent` : un pseudo est une donnée). Troisième entrée de `vite.config.ts` ; servie sous `/admin/` (production **et** recette).
- **Structure** : connexion (le bouton « Se connecter avec Google » de Google Identity Services, **script chargé par `admin.ts` et nulle part ailleurs**, en français ; en vérificateur factice un champ d'adresse) → barre (logo, environnement d'après l'adresse, « Se déconnecter ») + **menu** (Tableau de bord · Joueurs · Nouveautés et Message en direct (lot N2 : `#/nouveautes`, `#/message`) · Journal · Track, qui mène à `../track/admin/` · Jump, qui mène à `../jump/admin/`) + vues par `#/tableau`, `#/nouveautes`, `#/message`, `#/joueurs?q=&filtre=&page=`, `#/joueurs/<réf>`, `#/journal`. **Téléphone** : le menu est replié derrière « Menu ». Chaque action ouvre une fenêtre de confirmation (`<dialog>` natif : focus piégé, Échap) qui dit ce qui va se passer, demande ce qu'il faut (motif, pseudo à retaper) ; un 401 ramène à la connexion. La session est un cookie `HttpOnly` que la page ne voit jamais ; rien n'est gardé dans le navigateur.
- **Jeux (lot P)** : rubrique `#/jeux` du menu (`src/adminJeux.ts`) — l'interrupteur à trois positions de chaque jeu (Off · Aperçu · On, chacune confirmée), la clé d'aperçu (générer : le lien `…/<jeu>/?apercu=<clé>` n'est montré qu'**une fois** ; copier ; révoquer). Serveur : `apps/api/CLAUDE.md`, « Publication des jeux (lot P) ». Côté accueil : seuls les jeux que le serveur liste ont une cartouche (un jeu `off` disparaît) ; `compte: false` (jeu activé aujourd'hui) l'écarte de « n fini(s) sur m », de la tuile du classement et de la ligne à partager ; sur un aperçu de PR, un jeu pas encore `on` porte le badge « Brouillon » (`portail.brouillon`).
- **CSP propre à `/admin/`** (`firebase.json`, règle `/admin/**` après la règle `**`) : `default-src 'self'`, `script-src 'self' https://accounts.google.com/gsi/client`, `frame-src https://accounts.google.com/gsi/`, `connect-src 'self' https://accounts.google.com/gsi/`, `style-src 'self' https://accounts.google.com/gsi/style`, `img-src 'self' data:`, `frame-ancestors 'none'`, pas de `unsafe-inline` ni d'`eval` — **aucun script ni style en ligne** dans la page (les barres sont du SVG par attributs). Le script de Google n'est autorisé **nulle part ailleurs** (test `site.test.ts`) ; l'e2e `admin-panneau.spec.ts` sert la page **avec ces en-têtes** et vérifie qu'aucune violation n'apparaît. Les mentions légales le disent (FR et EN).
- **La courbe « joueurs par jour » est interactive** (`courbe()` de `admin.ts`, calculs purs `texteDeBarre` / `infobulle` de `adminDonnees.ts`, testés) : survol, toucher et flèches (← → Début Fin ; un seul arrêt de tabulation) montrent le jour et son nombre de joueurs dans une infobulle du graphe et dans la ligne `#courbe-lecture` ; une colonne entière par jour est sensible (`.admin-courbe__zone`), l'infobulle reste dans le cadre ; positions par attributs SVG (CSP sans style en ligne). Dans « Nouveautés », les lignes de l'éditeur sont des **fiches** (zone et « Retirer » en tête, français et anglais en zones de texte pleine largeur, sans retour à la ligne).
- **`?retour=/track/admin/`** : les pages d'outils de Track (`/track/admin/`, qui n'a plus de jeton) et de Jump (`/jump/admin/`, même porte) envoient ici pour la connexion ; une fois la session ouverte (ou déjà là) le panneau y retourne (`retourAdmin`, `RETOURS_PERMIS` : **une liste fermée de deux entrées comparées telles quelles**, jamais une adresse écrite par un tiers ; testé).
- **Aperçus de PR** : la page dit que le panneau n'y est pas utilisable (leur adresse n'est pas chez Google) ; elle n'a jamais le vérificateur factice.
- Tests : `npx vitest run apps/portail` ; e2e `apps/web/e2e/admin-panneau.spec.ts` (connexion refusée puis acceptée, cookie, tableau de bord, joueur › renommer › journal, déconnexion, format téléphone, axe ; `adminPanneau.ts` lance le portail seul et l'API avec le vérificateur factice). Captures : `CAPTURES=1 npx playwright test captures-lot-n1 --project=chromium`.
