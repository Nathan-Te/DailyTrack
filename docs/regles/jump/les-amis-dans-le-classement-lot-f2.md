## Les amis dans le classement (lot F2)
README : `docs/plateforme/lots/lot-F2-amis.md` ; composants communs : `packages/ui/CLAUDE.md`, « Les amis (lot F2) » ; client : `packages/profile/CLAUDE.md`. Le rendu du niveau, la simulation, les versions et les golden ne changent pas.
- **Où** : l'écran du classement du jour (`#leaderboard`, `screensUi.ts`, depuis l'accueil, l'arrivée et le résultat ; une archive a le même) reçoit le sélecteur « Tous · N / Amis · N » (`role="radiogroup"`, 44 px, jaune de Jump). Le top 5 de l'accueil et le top 10 de l'arrivée restent « Tous ». **Sans identité dans ce navigateur, sans serveur ou en démonstration (`?api=demo`) : aucun sélecteur, aucune requête** (`openBoard`, `main.ts`) ; un profil que le serveur ne connaît pas (`unknown_player`, `invalid_player`, `code_revoked` à `GET /api/amis`) n'en a pas non plus (`sansSelecteur`).
- **Chargé à la demande** : `classementAmis.ts` (`import()` à l'ouverture du classement d'un joueur qui a une identité ; une seule instance, `brancherAmis`) tire `@cdj/ui/src/amis` (sélecteur, feuille) + `CATALOGUE_AMIS` (fr + en) + `amis.css` : un seul fichier `classementAmis-*.js` / `.css`, **rien dans le premier chargement** (le préfixe `classementAmis-`, JS et CSS, est rangé parmi les fichiers à la demande de `scripts/budgets.mjs` et de `e2e/poids.spec.ts`, comme `manette-` ; **les deux mesures excluent désormais les mêmes fichiers**, dont `interrupteur-` et `course-` : `jump.jsCss` donne le même chiffre des deux côtés). Ce qui reste dans le premier chargement (+563 o mesurés, `docs/plateforme/budgets.md`) : les emplacements de `screensUi.ts` (`BoardUi.hote` : `amis`, `liste`, `message`, `tete`, `course`, `pied`, et les deux crochets `apres` / `echap`), `ref` dans les lignes (`rankView.ts`), `filtre` dans `urlOptions.ts`, le déclenchement dans `openBoard`. **Un module partagé avec ce fichier devient un fichier à part du premier chargement** (essayé : `home.ts`, `dailyInfo.ts`) : il reçoit donc `ligneClassement` en option (`ligne`) et ne lit pas `MEDAL_TYPE` (`MEDAILLES`, testé égal).
- **Requêtes** : un `GET /api/amis` à **chaque ouverture** du classement (le compteur « Amis · N » ; `lireAmis`) ; le classement « Amis » est une requête **séparée**, `GET /api/jump/day/<date>/board?filtre=amis` (`X-Player-Id`, jamais dans l'adresse), **seulement au choix d'« Amis »** — jamais avec la lecture regroupée du jour (`bundle`, qui porte « Tous »). Sa réponse est lue prudemment (`lireClassementAmis`, `amisLogique.ts`) : une ligne mal formée est écartée, **une réponse sans `filtre: "amis"` (serveur plus ancien) est refusée**, jamais montrée comme des amis. Toute erreur (hors ligne, `rate_limited`, réponse illisible) **retombe sur « Tous »**, retire `?filtre=amis` de l'adresse et dit une phrase discrète sous le sélecteur (`messageErreur` du socle).
- **Les lignes d'« Amis »** : toi et tes amis, tous (pas de limite de 10) ; le rang affiché est le rang **entre amis** (`rang`), le rang général se lit dans la feuille ; **ta ligne en encre** sur l'étiquette jaune (`.ligne--moi`, charte § 9) ; les amis qui n'ont rien fini ce jour-là (`absents`) en bas, sans temps (« — », « pas encore joué », `textesAmis`) ; **sans ami (`amis: 0`) : « Inviter un ami » sous la liste** (`classementAmisVide`, vers `../amis/`, la page du portail). « Voir la course du n° 1 » est caché en « Amis ».
- **La feuille d'un joueur** : toucher une ligne d'un autre joueur (« Tous » comme « Amis », absents compris) ouvre `feuilleJoueur` (`ficheJoueur(ref, date)` puis `afficher` ; « Ajouter en ami » / « Retirer » met le compteur à jour ; en « Amis », la liste se relit à la fermeture si l'amitié a changé). Le pseudo de la ligne devient un bouton dont le `::after` couvre toute la ligne (`.ligne__bouton`, `amis.css` : une cible de 44 px, un arrêt de tabulation). La référence publique (`ref`) vient du serveur ; **l'identifiant secret ne part qu'en en-tête**. Tout texte du serveur en `textContent`. **Échap ferme la feuille, pas l'écran** (`ecran()` de `screensUi.ts` laisse passer l'Échap tant que `hote.echap()` est vrai).
- **Adresse** : `?filtre=amis` (`URL_OPTIONS`, `readUrlOptions().filtre`) ouvre le classement sur « Amis » ; le choix l'écrit par `history.replaceState` (`adresseDuFiltre`, `adresseAvecFiltre` de `@cdj/profile`), le reste de l'adresse est gardé. Le choix tient tant que la page vit (rouvrir le classement le retrouve) ; un lien `?filtre=amis` n'ouvre pas le classement tout seul.
- **Manette (lot M1)** : `ECRANS_MANETTE` a la ligne de la feuille (`.dj-feuille`, A valide, B ferme), **la même que `ECRAN_MANETTE_FEUILLE` de `@cdj/ui/src/amis`** (copiée, pas importée : l'importer ramènerait les composants dans le menu à la manette ; `test/amis.test.ts` la compare). Le sélecteur (`role="radio"`) et les lignes (boutons) se parcourent à la croix.
- **Tests** : `test/amis.test.ts` (lecture prudente, lignes, absents, adresse du filtre, option d'adresse, manette ; module sur le petit DOM de `packages/ui/test/fauxDom.ts` : sélecteur, requêtes exactes, « Amis » séparé de « Tous », sans ami, repli sur erreur et sur un serveur plus ancien, sans identité, profil inconnu, réseau coupé, feuille et Échap, pseudo piégé, fermeture pendant une requête). Aucun e2e dans Jump : l'unique e2e du lot est celui du portail.
