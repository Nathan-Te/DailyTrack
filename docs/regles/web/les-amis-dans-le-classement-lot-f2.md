## Les amis dans le classement (lot F2)
README : `docs/plateforme/lots/lot-F2-amis.md` ; composants et règles communes : `packages/ui/CLAUDE.md`, « Les amis (lot F2) » ; client : `packages/profile/CLAUDE.md`. **Rien ne change dans la course ni la simulation** (golden inchangés).
- **Où** : la page du classement du jour (`boardScreen.ts`, `#board-screen`), pas la section de l'accueil (cinq lignes, « Tous »). **Tout est à la demande** : `boardScreen.ts` charge `amisClassement.ts` (`import()`, à chaque ouverture de la page ; le sélecteur, la feuille d'un joueur, le client des amis, `amisClassement.css`, le catalogue `CATALOGUE_AMIS` ajouté par `ajouterTextes`) ; **premier chargement : +352 o** (l'appel, `Online.base`, une ligne de `manette.ts` ; marge de `track.jsCss` : 83 o, `budgets.md`). Un module à la demande de plus que `boardView` partagerait avec lui le ferait éclater en un fichier (+134 o mesurés) : `lineEl` lui est **passé en paramètre**, `dom` et `i18n` s'importent sans coût.
- **Quand le sélecteur apparaît** : un serveur, pas la démonstration (`?api=demo`), et un joueur que le serveur connaît (`GET /api/amis` répond, une seule fois à l'ouverture : c'est aussi le compteur « Amis · N » ; `unknown_player` ou une panne : ni sélecteur ni feuille). La requête « Amis » (`GET /api/day/<date>/leaderboard?filtre=amis`, `X-Player-Id`) n'est faite qu'au choix d'« Amis » ou quand l'adresse porte `?filtre=amis` ; « Tous » est lu à l'ouverture comme avant (son nombre alimente « Tous · N »).
- **Le filtre** : `?filtre=amis` dans l'adresse (`lireFiltre`, `adresseAvecFiltre`, `history.replaceState`, les autres paramètres restent) ; le choix est gardé **le temps de la page** (variable du module, rien dans le navigateur). Une erreur (hors ligne, `unknown_player`, réponse illisible) **retombe sur « Tous »** avec une phrase discrète sous l'en-tête (`messageErreur` des amis).
- **Les lignes « Amis »** (`amisLignes.ts`, pur, testé par `test/amisClassement.test.ts` : lecture prudente, ordre du rang entre amis, ta ligne `moi`, absents en bas sans temps « pas encore joué », pas de limite de 50) : `rang` est le rang entre amis ; **sans ami**, `classementAmisVide` (« Inviter un ami » vers `../amis/`). Ce ne sont **pas des `.row`** (classe que lisent les cases « fantôme » de `fantomesJeu.ts`, dont les rangs sont ceux du général : pas de case en « Amis »). Le nom d'un autre joueur (« Tous » comme « Amis ») est un `role="button"` à `tabindex="0"` (pas la ligne entière : elle contient la case « fantôme », un bouton) ; toucher la ligne, Entrée ou A à la manette ouvre `feuilleJoueur` (`ficheJoueur(ref, date)`, rang général, « Ajouter en ami » / « Retirer ») ; fermée après un ajout ou un retrait, la liste « Amis » est relue. Pseudos en `textContent` seulement.
- **Manette (lot M1)** : la feuille est une ligne de `ECRANS_MANETTE` (`manette.ts`, l'égale de `ECRAN_MANETTE_FEUILLE` : elle y est écrite en clair, l'importer ferait entrer les composants des amis dans le morceau de la manette ; `test/manette.test.ts` le vérifie) ; le sélecteur (`role="radio"`) et les noms touchables sont des cibles du moteur (A active, B ferme la page).
