- **Effets** : traces de gazon arraché (`SKID_STYLE.turf`, fx.ts) ; brins clairs (`DUST.turf`) **seulement quand la voiture glisse** (un revêtement de course ne fume pas en ligne droite) ; voix propre (`SURFACE_SOUNDS.turf`) ; bandeau « Herbe de course » (`course.sol.turf`).
