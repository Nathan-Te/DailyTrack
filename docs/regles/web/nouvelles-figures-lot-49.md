## Nouvelles figures (lot 49)
README : `docs/lots/lot-49-identite-gameplay.md` ; le générateur : `packages/sim/CLAUDE.md`, « Générateur : identité des thèmes, nouvelles figures, variété (lot 49) ».
- **`?scenario=figure-<nom>`** (`&v=1` la variante 2, `&m=1` le miroir ; `?scenario=figure&f=<nom>` du lot 20 reste) : une figure seule, en boucle (`createFigureTrack`), **sur la palette de son thème** quand elle lui est propre (`figurePalette`, `scenarios.ts`). Un nom inconnu ramène au circuit d'essai.
- **`?scenario=figures`** ouvre d'abord **la page des nouvelles figures** (`pageFigures` de `scenarios.ts` : un écran posé sur la scène par `creerCadre`, `#figures-index`, jeu gelé tant qu'il est ouvert ; une ligne par figure de `FIGURES_LOT49` : titre, ce qu'elle demande, ses thèmes, « Essayer » et « Variante 2 », des liens qui gardent les autres paramètres de l'adresse) ; fermée (« ‹ TRACK », Échap, `#figures-tour`), on roule le tour des figures du lot 20. **Les outils du jeu lui sont prêtés** (`el`, `creerCadre`, `t`, `onLangue`) comme au Garage : `scenarios.ts` reste à la demande.
- **Textes** : `catalogue.course.figures.fr.ts` / `.en.ts` (clés `figures.index.*` et `figures.<nomEnCamelCase>.titre|quoi`), **chargés avec les scénarios** (`TEXTES_FIGURES`, ajoutés au traducteur par `ajouterTextes` dans `main.ts`), réunis à la zone « course » pour les tests (`catalogue.course.ts`) et `npm run traductions`. Le titre du scénario d'une nouveauté vient de ce catalogue (`figureLabel(nom, t)`), celui d'une figure du lot 20 reste le nom de la bibliothèque.
- Admin : le raccourci « Les figures » ouvre la page ; la carte d'un jour du planning dit « v18 · identité des thèmes (lot 49) ». Tests : `e2e/figures.spec.ts` (la page, deux touchers jusqu'à une figure, la réception en virage finie au temps de Node, les douze scénarios), `test/decorPose.test.ts` (pose des nouvelles figures), captures : `CAPTURES=1 npx playwright test captures-lot49 --project=chromium` → `docs/lots/lot-49-identite/captures/`.
