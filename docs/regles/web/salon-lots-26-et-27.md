## Salon (lots 26 et 27)
- **Le Salon** = deuxième mode : un circuit qui change **toutes les 10 minutes à heure fixe**, le même pour tous, avec les fantômes des autres joueurs et le classement de la session. Le circuit du jour reste le mode par défaut ; **le Salon ne touche jamais au circuit du jour** (ni records `cdj:best:*`, ni classement du jour, ni archives).
- **Sessions** : numéro de session = `floor(heure UTC en ms / durée)` (`salonSessionAt`, `salonSessionStart/End`, `packages/sim/src/salon.ts`) ; l'heure est lue **hors de `sim`** (jeu, serveur) et passée en argument. `salonCircuit(session)` : même générateur / thèmes / durées (30–40 s) que le circuit du jour (`generateCircuit`, generator.ts, que `dailyCircuit` utilise aussi), **graine propre** (`SALON_SEED_BASE` + session), id `salon-<session>-g<GENERATOR_VERSION>` ; `salonTheme(session)` : **jamais le même thème que la session précédente ni la suivante** (sessions paires = tirage, impaires = tirage hors des deux voisines : ne calcule que des thèmes). Changer le tirage = `GENERATOR_VERSION` +1.
- **Contrat `SalonApi`** (`apps/web/src/salonApi.ts`, servi par le serveur au lot 27) : `GET /api/salon/now` · `GET /api/salon/<session>/board?since=` (version : `unchanged` si rien n'a changé) · `GET /api/salon/<session>/ghosts?refs=a,b` · `POST /api/salon/<session>/submit {name, replay}` ; **le joueur est dans l'en-tête `X-Player-Id` (lot 32), un spectateur n'en envoie aucun**. **Un joueur n'est jamais désigné par son identifiant secret, mais par une `ref` publique propre à la session.** Le serveur rejoue la rediffusion sur `salonCircuit(session)` et n'enregistre que son temps ; envoi accepté pour la session en cours ou terminée depuis moins de **3 s** (`SUBMIT_GRACE_MS`, lot 31).
- **Jeu** (`apps/web/src/`) : `salonMode.ts` (`SalonController` : horloge, déroulé `playing → podium → switching` (la finale est un drapeau de `playing`), classement toutes les 5 s, fantômes, envoi ; `bootSalon`), `salon.ts` (logique pure, testée : `SalonClock`, `sessionClock`, `pickGhostRefs`, `overtakenBy`, `salonShareLine`, `modeHref`), `salonGhosts.ts` (`GhostField` : jusqu'à 5 fantômes + le tien, rediffusions rejouées au même pas, sans collision, voiture allégée d'une pièce, étiquette au pseudo de taille constante à l'écran), `salonUi.ts` (classement, podium), `main.ts` (`swapSalonCircuit` : nouvelle scène, anciens objets déplacés puis `dispose` ; `salonHost`). Déroulé (**refait au lot 31, retouché au lot 33**, voir « Finale du Salon ») : compte à rebours toujours visible, **finale de 15 s**, circuit suivant généré par le fil de travail pendant les 2 dernières minutes, **à l'heure pile la course s'arrête, le classement final s'affiche seul sur l'ancien circuit pendant 8 s (`PODIUM_MS`), puis le circuit change pour tout le monde**. **Plus d'attente des retardataires.**
- **Mode démo** `?mode=salon&api=demo` : `DemoSalonApi` (`salonDemo.ts`) joue le serveur dans le navigateur ; 8 à 15 pilotes fictifs « Démo … » (`demoPlan`, `salonPlan.ts`, déterministe par session) dont les courses sont calculées **dans un fil de travail** (`salonWorker.ts`, `salonJobs.ts`) puis **rejouées** (`replayRace`) : le temps annoncé ne compte pas, même pour eux ; tes courses passent par le même rejeu. `?salonMinutes=N` raccourcit les sessions (**démo et essais seulement** : avec une vraie API la durée vient du serveur). Sans API (et hors démo), « le Salon a besoin du serveur » et circuit du jour ; avec une API sans Salon (404), même message.
- **Touches** : **G** fantômes (tous / premiers seulement / aucun), **Tab** classement (bouton 🏆 sur petit écran), bouton **Salon** / **Jour** du menu (`modeHref`). Pas d'archives, pas de **N** / **T** / **H** dans le Salon.
- **Outils `?debug`** : `salonAt=<ms>` (heure de départ de l'horloge, démo), `__cdj.salon` (`state`, `session`, `board`, `ghosts`, `stats`, `setNow(ms)`, `setGhostMode`, `refresh()`). **Les tests de Salon utilisent des sessions de 10 minutes et avancent l'horloge avec `setNow`** : une session de 2 minutes en temps réel se termine pendant un test lent. Mesure : `MESURE=1 npx playwright test mesure-lot26` ; captures : `CAPTURES=1 npx playwright test captures-lot26`.
- **Règles** : un fantôme de plus coûte cher en rendu (chaque objet = un appel de dessin : voiture allégée) ; **toute nouvelle option d'adresse = une option de `adminLogic.ts`** (fait : « Le Salon », durée de session). Détail : `docs/lots/lot-26-salon.md`.
