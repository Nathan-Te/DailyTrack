## Groupes (lot C1, partie C)
README : `docs/plateforme/lots/lot-C1-retours-avatars-groupes.md` ; code : `src/groupes.ts` (routes, règles, classement des groupes, administration), `src/groupesScore.ts` (le score, **pur**), `src/groupesDepart.ts` (ce qui arrive à un groupe quand un joueur part), `scripts/groupesDemo.ts` (la recette) ; tests : `test/groupes.test.ts`, `groupesScore.test.ts`, `groupesDemo.test.ts` (SQLite **et** libSQL `file:`).
- **Modèle** (migration **réversible** : deux tables nouvelles ; retour arrière `DROP TABLE groupes` et `DROP TABLE groupe_membres`) : `groupes` (`id` public de 12 hexadécimaux tirés au hasard, pas un secret ; `name` / `name_key` — unicité sur la forme normalisée comme les pseudos —, `description` ≤ 140, `chef`, `avatar` = l'empreinte de l'emblème visible, `invitation`, `renomme_le`, `classement_masque`) ; `groupe_membres` (clé primaire = `player_id` : **un seul groupe par joueur**, `rejoint_le`, `arrivee` = le premier jour de Paris où il compte). Index : noms, jeton, `groupes_by_chef` (« Changer mon code »), `groupe_membres_by_groupe (groupe, rejoint_le)` (le plus ancien devient chef). Vidées par la remise à zéro, effacées avec le joueur (`departDuJoueur`), suivent « Changer mon code ».
- **Règles** : nom de 3 à 24 caractères (lettres, chiffres, espace, point, tiret, apostrophe ; mots refusés des pseudos) ; **30 membres au plus, vérifiés à l'écriture** (`INSERT … SELECT … WHERE COUNT < 30`) ; **le lien d'invitation est un jeton de 32 hexadécimaux tiré au hasard, gardé tel quel** (décision : tout membre doit pouvoir le montrer et le partager, ce qu'une empreinte à sens unique interdirait ; il n'ouvre que l'entrée dans ce groupe, le chef le renouvelle et l'ancien meurt) ; le jeton quitte l'adresse du navigateur à l'ouverture de la page ; **le chef** renomme (une fois par semaine, `429 group_rename_limit`), décrit, retire un membre, passe le chef, renouvelle le lien, change l'emblème (contrôlé comme un avatar), dissout ; **un membre quitte quand il veut** : si le chef part, le membre le plus ancien devient chef, et le dernier qui part dissout le groupe (avec son emblème et ses signalements).
- **Le score d'un groupe** (`groupesScore.ts`) : **la moyenne des 3 meilleurs résultats** de ses membres ce jour-là, dans la vue (Cumulé : ceux qui ont fini tous les jeux du jour au temps, somme de leurs temps ; un jeu : son temps ; Tower : sa hauteur, le plus grand est le meilleur — le sens vient de `estHauteur`, c'est-à-dire de la fiche du jeu). **3 classés au moins**, sinon le groupe est listé « Moins de 3 classés » sans rang. Égalité : la moyenne, puis le **4e résultat** (un groupe qui en a un devance celui qui n'en a pas), puis le **premier arrivé** (le plus tardif des 3 essais retenus), puis l'identifiant. **Un membre compte à partir du lendemain de son arrivée** ; un membre parti ne compte plus tout de suite ; un joueur masqué (N1) ne compte jamais (le classement du jour l'écarte) ; un groupe que l'administration masque n'est dans aucun classement. Exemple chiffré (testé) : 5 membres à 31,2 · 32,4 · 34,2 · 35,0 · 40,0 s → (31,2 + 32,4 + 34,2) / 3 = **32,6 s**, le 4e est 35,0 s.
- **Routes** (`X-Player-Id`, jamais dans l'adresse) : `GET /api/groupes/moi` (mon groupe, le lien, ce que je peux faire), `POST /api/groupes`, `GET /api/groupes/nom/<nom>?date=` (**la page publique** : fiche, membres, rang du jour dans chaque vue ; `public, max-age=0, s-maxage=30`), `GET /api/groupes/classement?date=&vue=` (public, `s-maxage=30`), `GET /api/groupes/invitation/<jeton>` (sans identité), `POST` `rejoindre`, `quitter`, `renouveler`, `retirer`, `chef`, `renommer`, `decrire`, `dissoudre`, `emblem` (+ `DELETE emblem`). L'emblème se signale comme une image de joueur (`POST /api/avatar/signaler { groupe }`).
- **« Mon groupe »** : `filtre=groupe` sur les quatre classements (portail et ses vues, Track, Jump, Tower), sur le chemin du filtre « Amis » (`classementAmis.ts`) : toi et les membres de ton groupe qui comptent ce jour-là, `rang` entre eux, `rangGeneral`, les membres qui n'ont rien fini en bas. `GET /api/amis` porte `groupe` (le nombre de membres) quand le joueur en a un : c'est ainsi que le sélecteur « Mon groupe » apparaît, sans requête de plus.
- **Coût** : le classement des groupes d'un jour lit le classement du jour déjà gardé par le portail (45 s) et **une recherche par clé primaire par joueur classé** (`groupe_membres` par paquets de 400), puis les groupes concernés ; **jamais toute la table des membres** ; il est gardé 45 s par instance. `couts.md` § 14. Administration (`/api/admin/groupes…`) : liste (recherche par préfixe du nom, 50 par page), fiche, renommer, retirer l'emblème, retirer un membre, changer le chef, masquer des classements, dissoudre (retaper le nom) — chacune confirmée et journalisée dans la même transaction.
- **Codes** : `invalid_group` 400, `group_name_taken` 409, `already_in_group` 409, `unknown_group` 404, `group_full` 409, `not_group_chief` 403, `group_rename_limit` 429, `unknown_member` 404 (`codes-erreur.md`, `CATALOGUE_AMIS`). `recette:seed` : 3 groupes (« Les Noctambules » dont « Démo » est le chef, « Les Rapides » avec un emblème, « Les Deux » à moins de 3 classés).
