# Un jeu Party (lot PA1)

## Un jeu Party (lot PA1)
**Catégorie `party`** (fiche : `categorie`, hors journée et hors cumul comme l'arcade ; règles : `docs/regles/racine/publication-des-jeux.md`). **Contrat serveur** : `src/jeux/party.ts`, `definirJeuParty({ fiche, nom }, contrat)` — le « niveau » d'un jour est **la graine du jour et rien d'autre** (`NiveauParty { jour, graine }`, `graineDuJour(code, jour)` de `@cdj/core/graine`, rendue par `GET /api/<jeu>/day/<date>` dans `contenu.graine`) ; le contrat n'écrit que `versions` (la version de la dérivation de la graine et du tirage), `decoder`, **`rejouer(niveau, texte)`** (le rejeu **valide le score**, comme pour tout jeu : le serveur ne garde que son résultat), `score`, `entrees` (et `mesures`, `ticksParSeconde`) ; **aucune médaille** (`seuils` rend `null`), aucun thème, aucun robot, aucun jour figé (`joursFiges` vide, pas de bloc `jours` dans la fiche : la chaîne de production, le garde-fou des jours et `figer` ignorent le jeu). Tout le reste (routes, ordre de validation, table commune `resultats_jeu`, classement, copies, aperçu, effacement, amis, « Mon groupe ») est le module des jeux. Tests : `test/partyJeu.test.ts` (graine reçue par le rejeu, refus par les codes de la liste), `test/partyPortail.test.ts` (hors journée, hors cumul), un jeu jouet dans `test/partyAide.ts`. **Pas encore fait (partie 2 du lot PA1)** : le jeu Party du jour (tour de rôle calculé à partir du jour, sans table), la règle « seul le jeu du jour accepte des envois classés ».


## Côté portail
Un jeu de catégorie `party` est **hors de la journée et du cumul** comme l'arcade (`categorie: "party"`, `compte: false`) : `categorieDuJeu` rend `party`, l'accueil et le profil le rangent avec l'arcade, `onglets` le place **après** les onglets d'arcade (même séparateur), `jeuxDuCumul` l'écarte, `jeuSuivant` n'annonce jamais « Journée parfaite ! » pour lui. **Pas encore fait (partie 2 du lot PA1)** : la section « Party » sous l'arcade (le jeu du jour en tête, « Classé aujourd'hui », les autres « Jeu libre », absente tant qu'aucun jeu Party n'est `on`) et l'onglet du seul jeu du jour.

## Côté kit (`packages/kit`)
`fiche.categorie === "party"` : le jeu passe une **`DefinitionJeuParty`** (la définition des autres jeux **moins** `themeDuJour`, `seuils`, `medaille`, `rediffusionDiamant`, `sansMedaille`, `sansFantome`) ; `brancherJeu` la complète par `definitionDeParty` (`types.ts`) : **un seul thème**, `THEME_UNIQUE` (`unique` : le catalogue du jeu a `theme.unique` et `accueil.phrase.unique`, la fiche n'a aucun thème), **aucune médaille ni fantôme**. Le jeu n'écrit que sa simulation, son rendu et ses textes ; le moule : `npm run nouveau-jeu -- --categorie party` (`docs/regles/racine/creer-un-jeu.md`). `FicheClient.categorie` vaut `party` (jamais « Journée parfaite ! » à l'arrivée).
