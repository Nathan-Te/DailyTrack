## État après le lot PB4 (le robot, la validation des tables, les médailles) — puis PB3, PB2 et PB1
- **Lot PB4 : le robot** (`packages/pinball-sim/src/robot.ts`) joue la vraie simulation et vise (il essaie des frappes sur des copies de l'état, la mission d'abord) avec des contraintes d'humain ; **chaque table est validée** (aucune bille coincée, chaque module touché, la mission réussie : `valider:pinball`, `refusees.ts`) ; **les vrais seuils** (Diamant = le meilleur de ses 4 parties de 2 minutes, Or / Argent / Bronze = des pourcentages du Diamant, constantes à régler par Nathan), figés avec la table (`figer:pinball`, `preparer:pinball`) ; essai `?robot`. `PINBALL_BOT_VERSION` 2, golden régénéré ; `PINBALL_SIM_VERSION` et `PINBALL_GENERATOR_VERSION` inchangés (3). Détail, mesures et valeurs de départ : `docs/pinball/lots/lot-PB4-robot.md`.

## Avant : l'état après le lot PB3 (les éléments des thèmes et les missions)

Détail : `docs/pinball/lots/lot-PB3-themes.md`.

## Où est quoi
- `packages/pinball-sim` : la simulation (pure, entière) — `partie.ts` (la physique), `table.ts` (la géométrie fixe et les modules), `reglages.ts` (**toutes les constantes de sensation, en un objet**), `entiers.ts` (division, racine, sinus), `generateur.ts` (la table du jour, les six emplacements), `themes.ts` (les quatre thèmes et leur règle), `rediffusion.ts`, `jours.ts` / `seuils.ts` / `medailles.ts` (jours figés, seuils figés avec la table ; **lot PB4 : `seuils.ts` calcule les seuils du robot et analyse une table**), **`robot.ts` (le robot : il joue et vise ; `jouerRobot`, `jouerRobotEnTranches`, ses constantes `ROBOT_*`), `validation.ts` (billes coincées, modules touchés, lancers dispersés), `refusees.ts` (les tables refusées, produit par `npm run valider:pinball`) ; le rapport : `npm run robot:pinball -w @cdj/pinball-sim -- --jours 30`**, **`src/variante.ts` : le seul endroit qui sait comment le jeu se classe**. Golden : `npm run golden:pinball -w @cdj/pinball-sim`, **jamais sans monter la version concernée** ; mesures : `npm run mesures:pinball -w @cdj/pinball-sim`. Consignes : `packages/pinball-sim/CLAUDE.md`.
- `apps/pinball` : `main.ts` (`brancherJeu`), `definition.ts` (la glue : la table, la scène et le rendu three.js à la demande), `scene.ts` (les entrées tenues, la boucle, le choix du rendu haute ou basse, la vibration), **`corps.ts` (le rendu three.js : le sol en texture, le meuble, les rails, les bumpers, les batteurs, la bille, la caméra qui cadre toute la table, les étiquettes), `dessin.ts` (le sol et le rendu à plat de secours, partagés), `essai.ts` (les options d'essai de l'adresse : `?qualite=`, `&reglages=`, `?debug&tune`), `bornes.ts` (les bornes des réglages d'essai et de la vue), `tune.ts` (le panneau `?debug&tune`)**, `niveau.ts` (la table du jour, chargée à la demande), `commandes.ts`, catalogues, `e2e/` (Playwright, ports 4189 et 8803 dans `playwright.config.ts`). Consignes : `apps/pinball/CLAUDE.md`.
- `docs/pinball/maquettes/cibles/` (lot PBV1) : les images cibles de la passe visuelle (Fête foraine et Océan, faites par une IA d'après des captures du jeu : une direction, pas un plan) et le jeu au moment de la demande ; `docs/pinball/lots/captures-pbv1/` : les comparaisons du lot.
- `apps/api/src/pinball.ts` (le contrat minimal : `definirJeuNeuf`), `apps/api/scripts/pinball-essais.ts` (le module d'essais de `smoke` et `recette:seed`), `apps/api/scripts/pinball-empreintes.ts`, `apps/api/test/pinball.test.ts`.

## Règles
- Les zones, la méthode et les règles de la plateforme sont dans `docs/pinball/passation.md` (générée) et le `CLAUDE.md` racine. Un lot de ce jeu reste dans ses zones et déclare tout nouveau spec e2e dans sa fiche (`e2e.specs`) **et** dans `apps/pinball/e2e/durees.json`.
- **Rien ne s'ajoute au premier chargement** qui ne soit pas à la demande (ligne de budget `pinball.jsCss`) ; un budget ne se relève qu'avec Nathan.
- **Mentions légales (règle de fidélité du lot R5)** : le jeu écrit dans le navigateur quatre clés, `pinball:records`, `pinball:reglages`, `pinball:aide:vu` et `pinball:identite:vue` (plus `cdj:apercu:pinball` et `cdj:commandes:pinball`). Les deux pages (`apps/portail/mentions-legales/index.html`, `apps/portail/legal/index.html`) doivent les décrire : **le test `apps/portail/test/mentions.test.ts` échoue tant qu'elles ne le font pas** dès que le jeu a dépassé son squelette (son catalogue n'a plus de texte « À remplacer ») et n'est pas un témoin. C'est un lot de la plateforme (zone partagée) : le proposer dans le README du premier lot du jeu, ne pas attendre le dernier.
