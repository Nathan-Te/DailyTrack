## Où est quoi
- `packages/gravity-sim` : la simulation (pure, entière : `partie.ts`), le monde et ses cases (`monde.ts`), le générateur du jour et le chemin sûr (`generateur.ts`), **le plan du jour, les sections à mode et le pilote du robot (`plan.ts`, `sections.ts`, `pilote.ts`, lot GR6)**, **les versions et les règles (`regles.ts`, lot GR5)**, la rediffusion, les seuils et les jours figés, **la préparation des jours (`preparation.ts`, `npm run preparer:gravity`)**, le robot (`robot.ts`) et son rapport (`npm run robot:gravity`) ; **`src/variante.ts` : le seul endroit qui sait comment le jeu se classe**. Golden : `npm run golden:gravity -w @cdj/gravity-sim`, **jamais sans monter la version concernée**.
- `apps/gravity` : `main.ts` (`brancherJeu`), `definition.ts` (la glue), `scene.ts` (l'orchestre du rendu Three.js et les entrées), `monde3d.ts`, `heros.ts`, `effets.ts`, `hud.ts`, `dessins.ts`, `couleurs.ts` (le rendu, à la demande avec la scène), `niveau.ts` (le niveau, à la demande), catalogues, `e2e/` (Playwright, ports 4188 et 8798 dans `playwright.config.ts`).
- `apps/api/src/gravity.ts` (le contrat minimal : `definirJeuNeuf`, le rejeu des changements du bouton), `apps/api/scripts/gravity-essais.ts` (le module d'essais de `smoke` et `recette:seed`), `apps/api/scripts/gravity-empreintes.ts`, **`apps/api/scripts/gravity-analyse*.ts` (l'analyse des parties : `npm run analyser -w @cdj/gravity`)**, `apps/api/test/gravity*.test.ts`.

## Règles
- Les zones, la méthode et les règles de la plateforme sont dans `docs/gravity/passation.md` (générée) et le `CLAUDE.md` racine. Un lot de ce jeu reste dans ses zones et déclare tout nouveau spec e2e dans sa fiche (`e2e.specs`) **et** dans `apps/gravity/e2e/durees.json`.
- **Rien ne s'ajoute au premier chargement** qui ne soit pas à la demande (ligne de budget `gravity.jsCss`) ; un budget ne se relève qu'avec Nathan.
- **Mentions légales (règle de fidélité du lot R5)** : le jeu écrit dans le navigateur quatre clés, `gravity:records`, `gravity:reglages`, `gravity:aide:vu` et `gravity:identite:vue` (plus `cdj:apercu:gravity` et `cdj:commandes:gravity`). Les deux pages (`apps/portail/mentions-legales/index.html`, `apps/portail/legal/index.html`) doivent les décrire : **le test `apps/portail/test/mentions.test.ts` échoue tant qu'elles ne le font pas** dès que le jeu a dépassé son squelette (son catalogue n'a plus de texte « À remplacer ») et n'est pas un témoin. **Fait (lot PG1 de la plateforme)** : les deux pages décrivent les quatre clés et la famille `gravity:…` ; le marqueur « À remplacer » a quitté le catalogue au lot GR5, le test générique traite Gravity comme livré. Une clé de plus = un lot de la plateforme (zone partagée) : le proposer dans le README du lot.
