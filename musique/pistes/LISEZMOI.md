# Les morceaux (sources)

Dépose ici le fichier d'un morceau (mp3, wav, flac, ogg, m4a, aac, opus), puis décris-le dans `../musiques.json` et lance `npm run musique`.
La procédure en trois étapes est dans `docs/plateforme/musique.md`. **Seuls des morceaux que tu as le droit de diffuser** : les tiens, CC0, CC-BY (avec le crédit exigé) ou achetés.
